# HIT 2.0 — 文献 NLP 抽取的成分-靶点活性数据（小而精）

- 官网：http://hit2.badd-cao.net/
- 文献：Yan D, Zheng G, et al. *HIT 2.0: an enhanced platform for Herbal Ingredients' Targets.* Nucleic Acids Research 2022;50(D1):D1238–D1243. https://academic.oup.com/nar/article/50/D1/D1238/6431818
- 分发格式：**网页检索 / 按条目导出**；无整库打包

| 指标 | 数量 |

| 成分-靶点活性对 | **10,031** |

| 文献覆盖 | PubMed 2000–2020 |

## 三个特点

**1. 每条关系带活性值与证据质量指示符（quality indicator）。**
靶点关系被细分为：直接/间接的激活或抑制、蛋白结合体（binder）、
酶的底物或产物（substrate / product）、以及成分处理后表达受调控的基因。
这种分型在别的库里通常被压平成一条「有互作」的边——做机制推断时信息量差别很大。

**2. 交叉链接最全。** TTD、DrugBank、KEGG、PDB、UniProt、Pfam、NCBI、TCM-ID 都有对接。

**3. 自动靶点挖掘。** HIT 支持从每日新发布的 PubMed 文献中自动挖掘潜在靶点，
用户可以检索并下载**尚未收录进 HIT 的成分**的相关文献摘要——相当于自带一个增量更新通道。

## 字段说明

| 字段 | 含义 |
|---|---|
| `HIT_id` | 记录主键 |
| `Ingredient_name` | 成分名 |
| `PubChem_CID` / `CAS` / `SMILES` | 化学标识符 |
| `Herb` / `Herb_latin_name` | 来源草药 |
| `Target_name` | 靶点蛋白名 |
| `Gene_symbol` / `UniProt_id` | 基因符号 / UniProt |
| `Organism` | 靶点物种 |
| `Activity_type` | 活性类型（IC50 / EC50 / Ki / Kd / % inhibition …） |
| `Activity_value` / `Unit` | 活性值与单位 |
| `Interaction_type` | 关系分型（activator / inhibitor / binder / substrate / product / regulator …） |
| `Direct_or_indirect` | 直接作用 or 间接作用 |
| `Quality_indicator` | 证据质量标签 |
| `Experiment` | 实验方法描述 |
| `PMID` / `Reference` | 文献 |
| `TTD_id` / `DrugBank_id` / `KEGG_id` / `PDB_id` / `Pfam_id` | 交叉引用 |

## 使用提示

- 规模只有 dbPTH 的 1/16，但**证据粒度更细**（带活性值、带质量标签）。
  合理定位：**dbPTH 做覆盖、HIT 2.0 做质控**——用 HIT 的高质量子集验证 dbPTH 边的可靠性。
- 没有批量下载，需要按成分/草药列表逐页抓取；1,237 个成分的体量，爬取是可行的。
- `Interaction_type` 一定要保留。把「抑制剂」和「表达被调控的基因」当成同一种边，
  是中药网络药理学结果不可重复的常见原因之一。
