# 中药 – 成分 – 靶点 – 微生物 – 疾病 数据集格式手册

本仓库整理 9 个数据库的**数据格式、字段含义、下载入口与分类关系**，并给出可直接运行的下载脚本。

> ⚠️ **开发会话内无法直接下载，改由 GitHub Actions 下载。**
> 本仓库的开发环境出口网络只放行 GitHub 与少数包管理源，上述 9 个数据库的全部域名
> （symmap.org、idrblab.net、disbiome.ugent.be、microbetcm.com、dbpth.biocuckoo.cn、
> tcmid.org、tcmsp-e.com、herb.ac.cn、hit2.badd-cao.net）在 CONNECT 阶段即被 403 拒绝，
> 明细见 [`DOWNLOAD_STATUS.md`](DOWNLOAD_STATUS.md)。
>
> **解决办法：让 GitHub 的 runner 去下载**——它有完整公网出口。
> 工作流 [`.github/workflows/fetch-datasets.yml`](.github/workflows/fetch-datasets.yml) 负责抓取，
> 数据提交到 **`datasets` 分支**，超过 90MB 的文件发布到 **Releases**。见下方「六、用 Actions 下载」。
>
> `samples/` 下的片段是**依据各库官方文档与原始论文还原的「结构示例」，不是真实下载数据**，
> 仅用于展示列名与取值形态。等 Actions 抓到真实数据后可直接替换。

## 一、分类总览

九个库按「在 中药→成分→靶点→微生物→疾病 这条链上占据哪一段」分为三类：

```
          ┌──────────────── A 类：中药内部链条 ────────────────┐
  中药/复方 ──→ 成分 ──→ 靶点(基因/蛋白) ──→ 疾病
     │                                          ▲
     │        ┌──── C 类：桥接 ────┐             │
     └──────→ │   微生物(菌群)      │ ────────────┘
              └────────▲───────────┘
                       │
          ┌──────── B 类：微生物侧 ────────┐
      药物/外源物 ──→ 微生物 ──→ 疾病
```

| 类别 | 数据库 | 在链条上的位置 | 规模量级 | 格式 |
|---|---|---|---|---|
| **A1 综合网络药理平台**<br>（药-成分-靶-病全链，广度优先） | SymMap ✅**已下载** | 草药 / 成分 / 靶点 / 疾病 **+ 症状层 + 证候** | **v2.0 实测**：703 草药、27,690 成分、20,965 靶点、14,434 疾病、2,364 中医症状、233 证候 | XLSX 批量下载 ✅ |
| | HERB (2.0) | 草药 / 成分 / 靶点 / 疾病 **+ 高通量实验 + 临床试验** | 7,263 草药、49,258 成分、12,933 靶点、28,212 疾病关联 | 网页分表下载 |
| | TCMID 2.0 | **复方** / 草药 / 成分 / 靶点 / 疾病 / 药物 **+ 质谱图谱** | 18,203 成分、1,356 药物、842 疾病、778 草药 MS 谱 | TXT 打包下载 |
| | TCMSP 2.3 | 草药 / 成分 / 靶点 / 疾病 **+ ADME 参数** | 约 500 草药、~30k 成分 | 网页表格，逐页导出 ⚠️ |
| **A2 成分-靶点专库**<br>（单段深挖，深度优先） | dbPTH 1.0 | **成分 → 靶点**（实验验证，跨 8 物种） | 165,967 互作、27,981 靶点、4,856 成分，约 21.4 GB | 整库打包下载 ✅ |
| | HIT 2.0 | **成分 → 靶点**（NLP 抽取 + 活性值 + 证据质量标签） | 10,031 成分-靶点活性对、2,208 靶点、1,237 成分 | 网页检索 / 按条目下载 |
| **B 微生物侧** | Disbiome | **微生物 ↔ 疾病** | 数千条实验记录，MedDRA + NCBI/SILVA 标准化 | CSV 导出 / JSON API ✅ 最易自动化 |
| | MDIPID | **药物 ↔ 微生物 ↔ 疾病**（三向） | DEIM 11,760 / MMDR 6,669 / MBDA 15,146 | Web 交互表，导出能力有限 ⚠️ |
| **C 桥接（最接近完整链条）** | MicrobeTCM | **中药/复方 → 微生物 → 疾病** | 171 疾病、725 微生物、1,032 草药、1,468 复方、15,780 成分 | Web 平台，检索 + 可视化 ⚠️ |

**选型建议（按用途）**

- 要**拼完整链条**（中药→成分→靶点→微生物→疾病）：以 **MicrobeTCM** 作骨架（它是唯一原生连通中药与微生物的库），
  中药侧的成分-靶点用 **dbPTH** 或 **HERB** 补齐，微生物侧的疾病关联用 **Disbiome** + **MDIPID** 补齐。
- 要**靶点最全**：dbPTH（实验验证 ITI 数量是 TCMSP 的 41.8 倍、HERB 的 34.5 倍、HIT 2.0 的 16.6 倍）。
- 要**复方粒度**：TCMID 2.0（唯一系统收录复方及其煎煮后成分变化）。
- 要**做经典网络药理 OB/DL 筛选**：TCMSP（OB ≥ 30%、DL ≥ 0.18 是该领域惯例阈值，参数只有它提供）。
- 要**接中医症状/证候**：SymMap（中医症状 ↔ UMLS 现代症状的人工映射是它的独家资产）。

## 二、逐库一段话概括

**SymMap** ✅ **已实际下载** — 中国中医科学院构建的整合库，特色是在「草药-成分-靶点-疾病」这条分子链之外，额外加了一条**症状链**：把草药对应的中医症状术语人工标准化后，经专家共识映射到 UMLS 的现代医学症状。因此它能同时从「分子机制」和「表型症状」两个方向连接中医与西医。下载最友好，`symmap.org/download`（**只有 http，https 拒绝连接**）直接给 XLSX。**下载页同时提供 v1.0 和 v2.0**：文献常引的 499 草药 / 4,302 靶点 / 5,235 疾病是 v1.0 的数字，v2.0 已到 703 / 20,965 / 14,434，并新增 233 条证候（SMSY）表——**请用 v2.0**。另一个实测发现：疾病表自带 `MedDRA_id` 和 `UMLS_id`，可以和 Disbiome 直接 join。

**MDIPID** — 浙江大学 IDRB 团队 2025 年发布，是目前**药物-微生物-疾病三向关系**最系统的库。它把关系拆成三类：MMDR（微生物及其蛋白如何改变药物的代谢与药效，6,669 条）、DEIM（药物/外源物如何改变菌群丰度，11,760 条）、MBDA（微生物与疾病的关联，15,146 条）。DEIM 记录到「变化方向 + 采样部位 + 动物模型 + 机制」的粒度，例如查 Finasteride 会返回 Ruminococcaceae UCG-002 丰度下降、样本来源 Stool。缺点是官方只提供 Web 交互表，没有公开的整库打包下载。

**Disbiome** — 根特大学维护，专做「微生物 ↔ 疾病」一件事，胜在**标准化程度与可自动化程度最高**：疾病统一挂 MedDRA、微生物统一挂 NCBI Taxonomy 与 SILVA，并且提供开放 REST API（`/api/disbiome/experiments` 等）可直接拉 JSON，也支持网页 CSV 导出。每条记录是一次实验观察：某菌在某疾病中「增加/减少」、身体部位、检测方法、以及文献出处。是这批库里唯一真正「一行代码拉全量」的。

**MicrobeTCM** — 本批中**唯一原生打通「中药/复方 → 微生物 → 疾病」完整链条**的平台。数据来自 419 篇体内实验文献的双人独立提取，覆盖 171 疾病、725 微生物、1,032 草药、1,468 复方、15,780 成分，还额外纳入 77 个穴位与 35 个穴位组方。除人工证据外还提供预测打分（疾病-微生物-靶点）。局限是只有 Web 界面、无批量下载接口，规模化使用需要按实体逐个抓取。

**dbPTH 1.0** — 2026 年发表的中药成分-靶点专库，**实验验证互作数量碾压同类**：165,967 条 ITI、27,981 个靶点、4,856 个成分，横跨 8 个物种并提供跨物种同源靶点映射，整库约 21.4 GB。相对 TCMSP / HERB / HIT 2.0 / BATMAN-TCM 2.0 分别是 41.81 / 34.47 / 16.55 / 9.72 倍的增幅。适合做需要高覆盖率靶点集的下游分析；代价是它只管「成分→靶点」这一段，草药与疾病侧需要另外接库。

**TCMID 2.0** — 最早（2013）的中药整合库之一，2.0 版的差异化价值在**复方粒度与质谱数据**：收录复方及其组成，并考虑到煎煮过程会产生新成分，单独收集了复方层面的成分；同时附 170 味草药的 778 张质谱图谱（用于辨别道地药材）与 729 个成分的 3,895 张谱图。需要做复方研究或药材质量溯源时优先考虑。

**TCMSP 2.3** — 中药网络药理学的**事实标准入门库**，价值不在数据量而在它是唯一系统提供 **ADME 参数**的库：口服生物利用度 OB、类药性 DL、Caco-2 透膜性、血脑屏障 BBB、半衰期 HL、Lipinski 五规则等十二项。领域惯例的「OB ≥ 30% 且 DL ≥ 0.18」活性成分筛选阈值就来自这里。短板是网站只能逐草药翻页查看，没有整库下载，批量获取需要脚本化抓取。

**HERB** — 北大团队构建，规模在综合库里最大（7,263 草药 / 49,258 成分 / 12,933 靶点 / 28,212 疾病关联），提供中药-成分-靶点-疾病之间的**六种两两配对关系**，并且区别于纯文献库的地方是它整合了**高通量实验证据**（基因表达谱）。HERB 2.0 进一步加入 8,558 项临床试验与 8,032 项 meta 分析，并为其中 1,941 项试验、593 项 meta 分析提取了明确结论——是这批库里唯一带临床证据层的。

**HIT 2.0** — 通过 NLP 从 2000–2020 年 PubMed 文献中抽取草药成分的靶点，得到 10,031 对成分-靶点活性数据（2,208 靶点 / 1,237 成分 / 1,250+ 草药）。两个特点：一是每条关系带**活性值与证据质量指示符**（直接激活/抑制、蛋白结合、酶底物或产物、表达调控等分类），二是**交叉链接做得最全**（TTD、DrugBank、KEGG、PDB、UniProt、Pfam、NCBI、TCM-ID）。还支持对 PubMed 新文献做自动靶点挖掘。适合当作证据质量较高的「小而精」参照集。

## 五、用 Actions 下载（推荐路径）

开发会话下载不了，但 GitHub 的 runner 可以。工作流已配好：

**自动触发**：每次改动 `.github/workflows/fetch-datasets.yml` 或 `scripts/gh_fetch.py`
并推到本分支，就会跑一次完整抓取。

**手动触发**：仓库 → Actions → *Fetch datasets* → Run workflow，可选参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `datasets` | `all` | 逗号分隔，如 `symmap,disbiome,herb` |
| `mode` | `download` | `discover` = 只探测链接不下载，用来先看看各站给出什么文件 |
| `max_mb` | `90` | 单文件上限。GitHub 单文件硬限 100MB，留 10MB 余量 |
| `release_large` | `false` | 开启后上限提到 1900MB，超 90MB 的文件发布到 Release 而不是跳过 |
| `include_huge` | `false` | 是否包含 dbPTH 整库（约 21.4GB，大概率超出 runner 磁盘） |
| `target_branch` | `datasets` | 数据提交到哪个分支 |

**产物去向**：

- 小于 90MB 的文件 → `datasets` 分支，每个库一个子目录
- 大于 90MB 的文件 → GitHub Releases（需开 `release_large`）
- `fetch_report.json` → 记录每个库**发现的真实链接**、文件大小、sha256；同时作为 artifact 保留 30 天
- 运行摘要 → Actions 页面的 Job Summary，含成功率表和发现的链接清单

### 脚本为什么是「发现链接」而不是「硬编码 URL」

这些库的静态文件名随版本变动，硬编码必然 404。`scripts/gh_fetch.py` 改为抓取各库下载页、
解析页面里所有 `href`/`src`（外加 JS 字符串里的裸 URL），按扩展名白名单筛出数据文件再下载。
**即使这一轮下载失败，报告里也会留下该站实际给出的链接**，据此校正比盲猜有效得多。

### 抓不到的四个库怎么办

TCMSP / MDIPID / MicrobeTCM / HIT 2.0 没有下载接口，工作流对它们只做链接发现。
先看一次 `mode=discover` 的报告，确认页面结构后再决定写爬虫，还是直接找作者要数据——
MicrobeTCM 和 MDIPID 都是人工策展的中等规模库，写信索取通常比爬取更快。

## 六、本地下载（备选）

```bash
bash scripts/check_hosts.sh                              # 先确认网络能通哪些站
python3 scripts/gh_fetch.py --out data --datasets all    # 链接发现 + 下载
python3 scripts/fetch_disbiome.py --out data/disbiome    # Disbiome 全量 JSON→CSV
bash scripts/download_all.sh                             # 直链方式（需链接未变）
```
