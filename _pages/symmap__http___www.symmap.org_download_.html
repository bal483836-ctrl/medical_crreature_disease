The SMHB file in tabular format includes all descriptive information about 499 herbs recorded in SymMap. The details of each column are as follows:

  1. Herb_id：the primary ID of each herb recorded in SymMap.
  2. Chinese_name：the herb name in Chinese.
  3. Pinyin_name：the herb name in Pinyin.
  4. Latin_name：the Latin name for the species of the herbs.
  5. English_name: the herb name in English.
  6. Properties_Chinese: the property description of the herb in Chinese using the terms from traditional Chinese medicine.
  7. Properties_English: the property description of the herb in English using the terms from traditional Chinese medicine.
  8. Meridians_Chinese: the meridian description of the herb in Chinese using the terms from traditional Chinese medicine.
  9. Meridians_English: the meridian description of the herb in English using the terms from traditional Chinese medicine.
  10. Function: the function description of the herb using the terms from traditional Chinese medicine.
  11. Class_Chinese: the classification of the herb in Chinese using the terms from TCM.
  12. Class_English: the classification of the herb in English using the terms from TCM.
  13. UsePart: the part of the herb plants to be used in medicine.
  14. TCMID_id: the cross reference of each herb in the TCMID database.
  15. TCM-ID_id: the cross reference of each herb in the TCM-ID database.
  16. TCMSP_id: the cross reference of each herb in the TCMSP database.
  17. HERBDB_id: the cross reference of each herb in the HERB database.
  18. Link_herb_id: the term id to which the discarded term is associated
  19. Suppress: the term has been discarded in new version of SymMap

The SMHB key file in tabular format includes all the search terms about 499 herbs recorded in SymMap. The details of each column are as follows:

  1. Herb_id：the primary ID of each herb recorded in SymMap.
  2. Field_name: the search field for the herb table, including the Chinese_name, pinyin_name, Latin_name and the English_name.
  3. Field_context：the search terms for all herbs recorded in SymMap.

The SMSY file in tabular format includes all descriptive information about 233 Syndrome recorded in SymMap. The details of each column are as follows:

  1. Syndrome_id: the primary ID of each TCM symptom recorded in SymMap.
  2. Syndrome_name: the name of Syndrome in Chinese.
  3. Syndrome_English: the name of Syndrome in English.
  4. Syndrome_Pinyin: the name of Syndrome in Pinyin.
  5. Syndrome_definition: the definition of Syndrome using the terms from traditional Chinese medicine.
  6. Type: types of syndrome terminologies.
  7. Suppress: the term has been discarded in new version of SymMap.

The SMYS key file in tabular format includes all the search terms about 1,717 TCM symptoms recorded in SymMap. The details of each column are as follows:

  1. Syndrome_id: the primary ID of each Syndrome recorded in SymMap.
  2. Field_name: the search field of the Syndrome table, including the Syndrome_name, Syndrome_PinYin, Syndrome_English
  3. Field_context：the search terms of all Syndrome recorded in SymMap.

The SMTS file in tabular format includes all descriptive information about 1,717 TCM symptoms recorded in SymMap. The details of each column are as follows:

  1. TCM_symptom_id: the primary ID of each TCM symptom recorded in SymMap.
  2. TCM_symptom_name: the name of TCM symptoms in Chinese.
  3. Symptom_pinyin_name: the name of TCM symptoms in Pinyin.
  4. Symptom_definition: the definition of TCM symptoms using the terms from traditional Chinese medicine.
  5. Symptom_locus: the locus of TCM symptoms using the terms from traditional Chinese medicine.
  6. Symptom_property: the property of TCM symptoms using the terms from traditional Chinese medicine.
  7. Type: type of symptom terminologies, including ontological and synonymous terms.
  8. Suppress: the term has been discarded in new version of SymMap.

The SMTS key file in tabular format includes all the search terms about 1,717 TCM symptoms recorded in SymMap. The details of each column are as follows:

  1. TCM_symptom_id: the primary ID of each TCM symptom recorded in SymMap.
  2. Field_name: the search field of the TCM symptom table, including the TCM_symptom_name and the symptom_pinyin_name.
  3. Field_context：the search terms of all TCM symptoms recorded in SymMap.

  9. MeSH_id: the cross reference of each MM symptom in the MeSH database.
  10. Suppress: the term has been discarded in new version of SymMap.

The SMIT file in tabular format includes all descriptive information about 19,595 ingredients recorded in SymMap. The details of each column are as follows:

  1. Ingredient_id：the primary ID of each ingredient recorded in SymMap.
  2. Molecule_name：the common name of each ingredient. Generally, we selected the first name appeared in the PubChem database.
  3. Molecule_formula: the molecule formula for each ingredient.
  4. Molecule_weight: the molecule weight for each ingredient.
  5. OB_score：the oral bioavailability score for each ingredient.
  6. PubChem_id: the cross reference of each ingredient in the PubChem database.
  7. CAS_id: the cross reference of each ingredient in the CAS database.
  8. TCMID_id: the cross reference of each ingredient in the TCMID database.
  9. TCM-ID_id: the cross reference of each ingredient in the TCM-ID database.
  10. TCMSP_id: the cross reference of each ingredient in the TCMSP database.
  11. Type: types of association between herbs and the ingredient, including QC, blood, metabolic and other ingredients.
  12. Link_ingredient_id: the term id to which the discarded term is associated
  13. Suppress: the term has been discarded in new version of SymMap

The SMIT key file in tabular format includes all the search terms about 19,595 ingredients recorded in SymMap. The details of each column are as follows:

  1. Ingredient_id：the primary ID of each ingredient recorded in SymMap.
  2. Field_name: the search field of the ingredient table, including the molecule_name, alias and the CAS_id.
  3. Field_context：the search terms of all ingredient recorded in SymMap.
